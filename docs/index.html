Capabilities

Everything, one keystroke away

Inspect and mutate data without ever leaving your shell.

🌳

Explorer tree

Schema → tables → columns & indexes, plus views, routines and sequences.

🗂

Multi-tab consoles

Persistent scratch SQL files, query history, favorites and autocomplete.

📊

Result grid

Paging, client-side sort & filter, and CSV / JSON / SQL-INSERT / xlsx export.

🔎

DDL popup

Table definitions, indexes and foreign keys at a keystroke.

🕸

In-terminal ERD

Braille canvas with crow's-foot notation, pannable and zoomable with the mouse.

✏️

Inline data editing

Edit cells, insert rows, delete with a SQL preview, and set NULL on nullable columns.

🔐

SSH tunnel

Reach databases behind a bastion with a per-connection SSH config — password or key auth.

🔁

Transactions

Toggle autocommit, then commit or roll back explicitly — works across all four drivers.

🔌

Auto-reconnect

Dropped connections are re-established transparently and your query is retried.

🌗

Dark & light themes

A palette for bright terminals too — one line in the config switches over.

Gallery

Rendered in-terminal

No GUI required — sharp, fast, and right where you work.

Install

Bring dbx to your machine

Prebuilt binaries ship on every release for Windows, macOS and Linux.

Download latest release → 
# One-line install (macOS & Linux) — detects your platform automatically
curl -fsSL https://raw.githubusercontent.com/go-routine-id/dbx/main/install.sh | bash

# Windows — x64: download dbx-windows-x86_64.exe, rename ke dbx.exe, taruh di PATH

# Upgrade later — no re-download by hand
dbx --self-update

macOS Gatekeeper? Jalankan xattr -d com.apple.quarantine /usr/local/bin/dbx
